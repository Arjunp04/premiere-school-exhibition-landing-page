# Premier Schools Exhibition Landing Page

> This project fulfills the responsive, accessible, pixel-perfect landing page requirements outlined in the assignment brief.

A simple, responsive landing page for the Premier Schools Exhibition. Built with plain HTML, CSS, and JavaScript — no frameworks.

## Live Link
[View Live Site](https://premiere-school-exhibition-landing.vercel.app/)

## Built With
- **HTML5** — page structure
- **CSS3** — styling and layout (BEM naming)
- **JavaScript (vanilla)** — sliders and swipe features

## Design Requirement
The implementation aims to be pixel-perfect, matching the provided design closely in spacing, typography, colors, animations, and overall UI details. The site is fully responsive and works across desktop, tablet, and mobile devices.

## Breakpoints
- **Mobile:** under 480px — single column, swipeable card slider with pagination dots
- **Tablet:** 480px – 1024px — 2-column grid
- **Desktop:** 1024px and above — 4-column grid

## What's Included

**Accessibility**
- Skip-to-content link at the top of the page
- Visible focus outlines for keyboard navigation
- Sliders freeze automatically if the user has reduced motion turned on in their system settings
- Pagination dots and carousel work with keyboard (Tab, Enter, Space)

**Interactive Sections**
- Hero image slider with swipe, hover-to-pause, and manual arrows
- "Choose the School" cards — grid on desktop, swipeable slider with dots on mobile
- Background images with soft fade effects behind text

- Checked with W3C HTML/CSS validator
- Checked with axe accessibility checker

## How to Download and Run Locally

1. Go to the GitHub repository page.
2. Click the green **Code** button, then **Download ZIP** (or use `git clone <repo-url>` if you have Git installed).
3. Unzip the folder (skip this step if you used `git clone`).
4. Open the folder in your code editor (e.g. VS Code).
5. Open `index.html` using one of these:
   - **Option A — Directly:** Double-click `index.html` and it opens in your default browser.
   - **Option B — Live Server (recommended):** Install the "Live Server" extension in VS Code, right-click `index.html`, and select **"Open with Live Server"**. This auto-refreshes the page whenever you save changes.

No installation or build setup needed either way.
